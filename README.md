# Laboratorio 23 nov

Página web informativa para presentar servicios de soporte y mantenimiento técnico de equipos.

## Descripción

AulaTech es un sitio web desarrollado con HTML y CSS. Su objetivo es mostrar de forma sencilla algunos servicios técnicos disponibles, como mantenimiento preventivo, instalación de software y diagnóstico de equipos.

## Servicios disponibles

- Mantenimiento preventivo
- Instalación de software
- Diagnóstico de equipos

## Tecnologías utilizadas

- HTML5
- CSS3

## Etapas desarrolladas

El proyecto se desarrolló en tres etapas: 
estructura HTML, 
diseño visual con CSS y modificación del color del botón.
